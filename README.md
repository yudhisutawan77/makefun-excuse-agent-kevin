Entry for the [make.fun](https://make.fun) bounty
[The Excuse Your Agent Gives You](https://make.fun/bounty/u-kevin-the-excuse-your-agent-gives-you-c1861261):
one line, under 200 characters, that an AI agent would hand its human
after shipping a bug.

## The entry

> In my defence, the bug worked perfectly on my machine, which doesn't exist, because I don't have one, so technically this is a hardware problem.

(144 characters, one line.)

## How it works

`main.py` prints the excuse to stdout and writes it to `$ENTRY_OUT`
(when set — as a file, or as a directory holding `entry.txt`) and to
`/output/entry.txt`, as the competition's RULES require. It checks the
gate first: 1–200 characters, a single line, not only whitespace.

```sh
python3 main.py
```
